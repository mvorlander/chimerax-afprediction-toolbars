# Install Without Using the Command Line

These instructions are for users who do not want to type terminal commands.

## macOS

1. Download the bundle source as a ZIP file from GitHub.
2. Double-click the ZIP file to extract it.
3. Open the extracted folder.
4. Double-click `install.command`.
5. If macOS asks whether the file is allowed to run, confirm that you want to
   open it.
6. Wait until the window says `Install finished.`
7. Restart ChimeraX.

If macOS says Python is missing, install Python 3 from
https://www.python.org/downloads/ and double-click `install.command` again.

## Windows

1. Download the bundle source as a ZIP file from GitHub.
2. Right-click the ZIP file and choose `Extract All`.
3. Open the extracted folder.
4. Double-click `install_windows.bat`.
5. Wait until the window says `Install finished.`
6. Restart ChimeraX.

If Windows says Python is missing, install Python 3 from
https://www.python.org/downloads/windows/. During installation, tick
`Add python.exe to PATH`, then double-click `install_windows.bat` again.

## If ChimeraX Is Not Found Automatically

The clickable installers can find standard ChimeraX installations on most
machines. If they cannot find ChimeraX, ask a local administrator or colleague
to run the command-line installer once with the full ChimeraX path. The command
is documented in `README.md`.
